# AI Module Integration Guide

This document outlines how the Node/Express backend should interact with the AI duplicate-detection module for the PRJ-126 Land Profiling project.

## Running the Inference API

The AI module exposes a lightweight FastAPI service. It should be run locally alongside your backend.

**Startup Commands (from the `ai` directory):**
```bash
# Setup (if not already done)
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Linux/Mac
pip install -r requirements.txt

# Start the server
uvicorn api:app --port 8000
```
*Note: Ensure you are running Python 3.11+.*

## API Endpoints

### 1. Health Check
- **Endpoint**: `GET /health`
- **Expected Response**:
  ```json
  {
    "status": "ok",
    "message": "Duplicate Detection API is running"
  }
  ```

### 2. Predict Duplicate
- **Endpoint**: `POST /predict`
- **Port**: `8000` (default)
- **Headers**: `Content-Type: application/json`

#### Request Format
Send the two `LandAsset` records you want to compare as `asset_a` and `asset_b`.

```json
{
  "asset_a": {
    "asset_id": "AST-100",
    "land_id": "LND-100",
    "survey_no": "SY-888",
    "owner_name": "Sarah Connor",
    "area": 25.5,
    "latitude": 20.1234,
    "longitude": 80.5678,
    "asset_type": "Agricultural",
    "description": "Large farm"
  },
  "asset_b": {
    "asset_id": "AST-101",
    "land_id": "LND-100-DUP",
    "survey_no": "SY 888",
    "owner_name": "Connor Sarah",
    "area": 25.55,
    "latitude": 20.1235,
    "longitude": 80.5677,
    "asset_type": "Agricultural",
    "description": "Large farm"
  }
}
```
*Missing fields should be passed as `null` or omitted entirely.*

#### Response Format
```json
{
  "duplicate_probability": 0.995,
  "is_duplicate": true,
  "features": {
    "survey_similarity": 1.0,
    "owner_similarity": 1.0,
    "area_similarity": 0.998,
    "location_similarity": 0.9924,
    "land_id_similarity": 0.8,
    "asset_type_match": 1.0,
    "description_similarity": 1.0,
    "coordinate_validity": 1.0
  },
  "reason": "Flagged as duplicate due to highly similar survey numbers, similar owner names, near-identical areas, highly overlapping geographic locations."
}
```
- `is_duplicate` represents the final boolean decision (using the validated threshold of 0.22).
- `duplicate_probability` is the raw Random Forest confidence score.
- `reason` is a human-readable explanation generated by the module that can be directly displayed to the user in the frontend.
